Changelog for Busbridge for HDL Buspro (until 2.1: HDL Buspro server)

List of changes, newest changes first.
('+' = new feature, '-' = removed feature, '*' = changed feature)

Version 2.1.0
 * HDL Buspro server is now called Busbridge for HDL Buspro. How it's installed, run and updated stays the same.
 + A new look for the web pages. They work well on phones, follow your light or dark mode, and can be added to your home screen.
 + The Status and Activity pages update live, without reloading.
 * Your actions come first on the Actions page, each with a big Run button, and with how to call it folded away until you need it.
 * The pages' styles and scripts come from the server itself, so the pages also work when the Internet is down, and load nothing from other sites.
 + Custom actions can control scenes and sequences, e.g. "Movie night" or "Good night".
 * Custom actions show what each parameter means for the chosen operation, e.g. Area and Scene number, and check that the values fit before the action is saved.
 * Bugfix: Single channel control in custom actions sent an incomplete command. Parameter 3 is now its run time in seconds.
 * "UV switch control" is now called universal switch control, like HDL calls it.
 * The Components page is now called Devices, like in the app and in HDL's own subnet and device IDs.
 + Devices can be removed from the Devices page. Ones that haven't been heard on the bus since the server started are marked, so old ones are easy to spot.
 + Devices answering at the same address are marked "Address conflict" on the Devices page, like in HDL's setup tool, since commands to that address reach both.
 * The server searches for devices three times when it starts, since some answers get lost when dozens of devices answer at once.
 * Many more kinds of devices are recognized (238 types, up from 91), so fewer show up as unknown.
 * IP modules are recognized, and a device renamed in HDL's setup tool gets its new name here on the next search.
 * An action's address and cURL example start with https:// when you opened the page over HTTPS, e.g. through a proxy.
 + The port can be changed with -Dhdlserver.port=<port>. See "Settings" in README.md.
 * The server sends to the bus as 11/252 with its own device type (0xFFFB), so it can be told apart from the Android/iOS app (11/253) in the bus log and in HDL's Setup Tool.
Version 2.0.0
 * Needs Java 17 or later (was Java 8). If yours is older, the server tells you what to do. See "Upgrading to version 2" in README.md.
 + Run any action straight from the Actions page.
 + Activity page: what was done when, and from where.
 + Status page: is the server well, and is the HDL bus alive.
 + The web pages also work over Tailscale.
 + update.sh updates the server in one go, and only if the new version runs on your Java.
 * The setup guide in README.md runs the server as a service that starts by itself and restarts if it ever stops.
 * Built on new, maintained libraries, so it keeps getting security fixes. Your actions, key and IFTTT applets work as before.
Version 1.1.1
 * Bugfix: Old log files were never deleted, so over the years they could fill up the disk. Logs older than 30 days are now deleted, also when the server starts.
Version 1.1.0
 * Security: Fixed several security vulnerabilities. Everyone running an earlier version should upgrade.
 * The web pages only answer to IP addresses and local host names, unless others are allowed. See "Updating the server" in README.md.
 * Upgraded libraries, among them Spark to 2.9.4 and Jetty to 9.4.58.
 * Bugfix: Calling a dimmer action with a wrong key answered 500 rather than 401.
 * Bugfix: Calling a custom action that doesn't exist answered 500 rather than 404.
 * Bugfix: Deleting an action didn't always remove its aliases.
 * Bugfix: Creating an action now says whether it worked, and why not.
 * Bugfix: Actions called at the same time could get their commands mixed on the bus. They're now sent one at a time.
 * IFTTT's Maker service is now called Webhooks.
Version 1.0.3
 * Upgraded from using Spark version 2.5.3 to version 2.8.0. See https://github.com/advisories/GHSA-76qr-mmh8-cp8f .
 * Fixed now broken link.
Version 1.0.2
 + Added support for curtain switch control (0xE3E0) in custom action.
Version 1.0.1
 + Added support for single channel control (0x0031) in custom action.
 * Bugfix: Deletion of actions did not work properly.
 * Authentication key only has to be 25 characters long.
Version 1.0.0
 + Initial release.
